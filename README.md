# Language Translation Tool

**Task 1** - CodeAlpha Artificial Intelligence Internship

## 📋 Project Description
A simple and user-friendly web app that translates text from one language to another using Google Translate API.

## ✨ Features
- Supports 100+ languages
- Clean and responsive interface
- Real-time translation
- Shows detected source language

## 🛠️ Technologies Used
- Python
- Streamlit
- googletrans (Google Translate API)
